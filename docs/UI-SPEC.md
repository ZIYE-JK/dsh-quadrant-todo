## 3. 组件清单

### 左侧 rail（新增）
- 三个纵向导航项：**做计划**（日历图标，默认选中态为白色圆角卡片）、**视图**（宫格图标）、**专注**（沙漏图标）
- 底部：圆形头像

### 左面板（部分新增）
- **收集箱**（新增概念）：文件夹图标 + 计数 + 折叠箭头
- **月历**：`‹ 2026年11月 ›` + `回到今天`；周一为一周起始；每格下方圆点表示当天有待办（颜色随象限/状态变化）
- **分类列表**：`全部`（◎，选中态灰底）、`无分类`（⊘）、然后是按分类名 + **emoji 图标**（🚗汽车 / 🎉运动 / 🏠家庭 / 🐣个人 / 💻工作）
- 底部 `+ 新建分类` 胶囊按钮

### 顶部栏
- 左：快捷添加输入框，占位文案 `添加计划到「收集箱」，回车即可保存`
- 右：**通知开关**（喇叭图标，浅绿=开）+ 日历图标

### 四象限区（核心新增）
- 四张卡片，每张：标题（两侧 emoji + 象限名）+ 右上角 `+` 新建
- 空态：插画 + 文案
  - 紧急不重要 → 「交给别人或自己做」
  - 重要不紧急 → 「规划后再做」
- 任务行：左侧圆形图标（红圈=未完成 / 绿勾=已完成）、标题；当前选中行整行粉底高亮；已完成行文字变灰

### 右侧详情面板（新增）
- 红色圆形图标 + 标题
- `+添加子计划`（蓝色链接）→ **子任务**
- 备注输入区，占位 `选填：这是我要写的书写内容`
- 分隔线
- 属性行（左标签 / 右值 + `>` 箭头）：
  - 计划分类 → `无分类`
  - 重要优先级 → `❗❗❗ 重要且紧急`
  - 完成期限 → `当天`
  - 重复 → `每月`
- 右下角 `保存` 按钮

## 4. 与现有数据模型的差距

现有模型（`lib/model.js`）：`priority: high|medium|low`、`category: string|null`（≤24 字）、`dueDate`、`dueTime`、`repeat`、`completions`。

| 图中元素 | 现状 | 需要新增 |
|---|---|---|
| 四象限（重要且紧急…） | 只有 3 档 `priority` | **`quadrant` 字段**（4 值）或把 priority 重解释为象限 |
| 分类 emoji 图标 | 分类只是裸字符串 | **分类元数据**（名称 → 图标），需独立存储 |
| `+添加子计划` | 无 | **子任务**（新字段 + 完成语义 + agent 工具参数） |
| 收集箱 | 无 | **收集箱语义**（未排期池？还是独立视图？）需定义 |
| 通知开关（喇叭） | 无 | **通知设置**（宿主端持久化，因为飞书在宿主端发） |
